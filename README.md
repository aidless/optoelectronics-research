## 六个立项方向

| 编号 | 方向 | 周期 | 一句话定位 |
| --- | --- | --- | --- |
| P1 | CPO 封装良率与光电协同测试 | 4 年 | 键合应力—FAU 对准—光电同测耦合机理与良率预测（产业化确定性） |
| P2 | III-V 激光器异质集成上硅 | 4 年 | 硅间接带隙难发光的根问题，卡住 200G+ 光源（产业化确定性） |
| P3 | 光计算能效口径与评测基准 | 3 年 | 方法学空位，做成了能立标准 |
| P4 | AI / 智能体逆向设计光子器件 | 3 年 | 出论文快，与 EDA 工具链结合（学术产出速度） |
| P5 | 新型电光材料晶圆级集成（PZT/TFLN） | 4 年 | 载流子耗尽型逼近极限后的下一代路线（学术产出速度） |
| P6 | 硅光健康监测临床验证 | 4 年 | 大规模临床样本数公开未覆盖＝核心研究空间（长期壁垒） |

优先级建议：产业化确定性取 P1+P2，论文速度取 P4+P5，长期壁垒啃 P6，P3 方法学空位能立标准；第 1 年先启动 P3+P4，P6 的伦理与临床最早起步。详见 `proposals/00_立项总览.md`。

## 深挖对齐后的关键结论（避免沿用被推翻的旧表述）

- **P3「65.5 TOPS/W」是误标**：一手 NSR 综述证实 65.5 是 Envise 吞吐量（65.5 TOPS），能效实为 0.81–0.84 TOPS/W，不能与清华太极 160 TOPS/W 并列当能效值；LightGen 是上海交大陈一彤团队成果（Science 2025-12），非清华。IEEE P1959/P1960 通用 ML 能效标准与 Nature Nanotech 光计算量化方法学已出现，P3 须转向「光计算专用分层口径 + 转换开销记账基准」差异化定位。
- **P5「晶圆级良率未公开」前提被推翻**：imec/根特 arXiv:2605.28971 已公开 TFLN 微转移印刷到 4×200mm 晶圆、印刷良率 >95%；差异化须收窄到 PZT 铁电畴器件晶圆级一致性 + 良率-成本模型。
- **P6 Happy Ring FDA 510(k)=K254000 已核实**（85 例 / 850 次有创动脉压对照），但批准范围窄于宣传（仅 22–50 岁点测、仅显示不诊断）。人体大规模多中心临床样本数仍确认未覆盖。
- **P2「四家占 90% 产能」无一手出处**，TrendForce 给出的是五家不同名单；Intel 加速寿命测试 <0.1 FIT 一手数据推翻「可靠性公开未覆盖」的旧表述。
- **P4 已有团队发表逆设计超表面同口径仿真—实测对照**（50.4% vs 50.2%），须把缺口收窄为针对该智能体框架。

真正保留的科学空白（需本项目实测填补）：P1 键合应力→插损/波长漂移敏感系数、光电同测吞吐基准；P6 大规模多中心临床样本与跨人群分层误差。

## 复现

```bash
# 立项书自检（无需外部依赖）
python3 proposals/check_proposals.py

# 从 evidence JSON 重建三份聚合报告（工作目录设为仓库根）
python3 scripts/build_all_tracks_report.py
python3 scripts/build_latest_report.py
python3 scripts/build_deepdive_report.py
```

`build_*.py` 默认从 `outputs/deep-research/` 读取；在本仓库内复现时把脚本里的 `BASE` 改为 `evidence`，输出目录按需调整即可。
